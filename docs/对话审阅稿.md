# cod fishing mod 对话审阅稿

版本：1.6.1 · 作者：florain

可直接修改每条的“中文”或“English”内容；仅修改中文也可以，修改完后告诉我，我会按中文同步英文并导入模组。

保留文本键和章节结构。@ 是玩家姓名，^ 是信件换行，#$b# 是对话换页，$h 是表情控制符，请保留这些标记。这里只整理当前使用的角色对话与信件；物品说明、任务日志等仍在《文案审阅稿.md》中。

标注“共用”的文本修改后，会影响列出的所有场景或人物。本文件是专项审阅稿，请勿直接用现有的全量 sync-text.ps1 Import 导入。
